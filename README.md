# open-webSite

架空の企業「株式会社Yuuseinovation」のコーポレートサイト（静的HTML/CSS/JS）。

※社名・住所・電話番号・メールアドレスはすべて架空のものです。

## ページ構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | トップ（ミッション／事業／数字／社長／お知らせ） |
| `business.html` | 事業内容（YUUSEI DX／YUUSEI TAILOR） |
| `president.html` | 社長紹介（メッセージ／プロフィール／趣味／Q&A） |
| `company.html` | 会社概要（バリュー／会社情報／沿革／アクセス） |
| `recruit.html` | 採用情報 |
| `contact.html` | お問い合わせ（デモフォーム・実際には送信されません） |

## 表示方法

`index.html` をブラウザで開くか、ローカルサーバーを起動してください。

```sh
python3 -m http.server 8000
# → http://localhost:8000
```
